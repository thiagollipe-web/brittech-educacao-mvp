3. Como ligar a medição — criar a propriedade GA4

Fazer com login no Google Analytics, na conta thiagollipe@gmail.com. Não custa nada; não criar conta de Google Ads.

  1. Abrir https://analytics.google.com e entrar com thiagollipe@gmail.com.
  2. Admin (engrenagem, canto inferior esquerdo) → Criar → Propriedade.
  3. Nome da propriedade: Brittech Educação. Fuso horário: (GMT-03:00) Horário de Brasília. Moeda: Real brasileiro (BRL). Avançar.
  4. Detalhes da empresa: setor Educação, tamanho Pequena (1 a 10 funcionários); marcar os usos pretendidos (ex.: “Medir o engajamento” e “Gerar leads”). Criar e aceitar os termos.
  5. Criar o fluxo de dados: Web. URL do site: thiagollipe-web.github.io. Nome do fluxo: Brittech Educação — site principal. Criar.
  6. Copiar o ID de medição exibido (formato G-XXXXXXXXXX).
  7. Usar UM só ID em todas as páginas. Todas as páginas estão no mesmo host (thiagollipe-web.github.io) e o GA4 distingue os sites pelo caminho da página (/brittech-educacao/, /brittech-educacao-mvp/, /brittech-educacao-aulas/). Um único fluxo basta; fluxos separados só seriam necessários para separar os dados por site.
  8. Em cada um dos 6 arquivos do item 1, trocar G-XXXXXXXXXX pelo ID real (são 3 ocorrências por arquivo: 1 no comentário de instrução e 2 no código — trocar as 3, ou pelo menos as 2 do código). Publicar os arquivos.
  9. Conferir: no GA4, abrir Relatórios → Tempo real e visitar as páginas aceitando os cookies. A visita deve aparecer em até ~1 minuto. Para testar sem sujar os dados, usar Configurar → DebugView com a extensão Google Analytics Debugger.

Sem o ID real, nada é medido — e isso é proposital. Com o placeholder G-XXXXXXXXXX, o carregador nem cria a requisição ao Google. Sem aceitar os cookies, também nada dispara. O banner aparece mesmo sem o ID, para o consentimento já funcionar desde já.

4. Como o consentimento funciona

  • Na primeira visita, o banner aparece no rodapé. Aceitar grava brittech-consent-v1 = granted no navegador e carrega o gtag.js; Recusar grava denied e nunca carrega nada do Google.
  • Enquanto não há decisão, nenhuma requisição vai para googletagmanager.com nem para google-analytics.com. O código do gtag só existe como função local (stub) até o aceite.
  • Depois da decisão, o banner some e não volta. Para mudar a escolha, é preciso limpar os dados do site no navegador (ainda não há botão “rever cookies” nem página de política — ver item 6).
  • O banner é fixo no rodapé, some após a escolha e não empurra o conteúdo — não cobre CTAs de forma permanente.

9. Como verificar sem aceitar (nenhuma requisição ao Google)

  1. Abrir a página com o console de rede do navegador (aba Rede/Network).
  2. Antes de clicar em “Aceitar”, filtrar por googletagmanager e por google-analytics: não deve aparecer nenhuma requisição. O único googletagmanager existente está dentro da função loadGtag(), que só roda após aceite + ID real — conferir por leitura de código: o script é criado com document.createElement('script') dentro dessa função.
  3. Clicar em “Recusar”: o banner some e continua sem nenhuma requisição ao Google.
  4. Depois de preencher o ID real, clicar em “Aceitar” e conferir que aparece a requisição gtag/js?id=G-... e que a visita aparece no Tempo real do GA4.
